# Ke Li's personal homepage

This repository hosts [ak-dream.github.io](https://ak-dream.github.io/).

The site is based on the minimal `academic` theme from
[Galaxy-Dawn/academic-homepage-templates](https://github.com/Galaxy-Dawn/academic-homepage-templates).
Edit `config.js` to update the site's content.

## Customization

All homepage content lives in `config.js`:

- Update the basic identity fields at the top.
- Replace the sample entries in `stats`, `publications`, `projects`, `news`, `education`, and `experience`.
- Use an empty list (`[]`) to hide a section.
- Use an empty string (`""`) to hide an optional link.
- Put a profile photo or CV in an `assets` folder, then set `photo` or `links.cv` to its relative path.
